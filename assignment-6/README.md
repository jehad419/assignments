Assignment Title: Create a Simple Personal Profile Webpage Using HTML
Objective: To practice HTML Structural Tags, Text Formatting, Forms, Tables, Multimedia,
Semantic Elements, and Interactive Elements.
Assignment Tasks
Create a simple personal profile webpage using HTML. Your webpage must include the
following elements:
1. Structural Tags
○ Use <html>, <head>, <title>, and <body>.
○ Add a heading and a paragraph about yourself.
2. Text Formatting
○ Use bold, italic, underline, and highlighted text.
3. Form
○ Create a form with the following fields:
■ Name
■ Email
■ Password
■ Gender (Radio buttons)
■ Hobbies (Checkboxes)
■ Submit button
4. Table
○ Create a table showing your academic information.
○ Include at least 3 rows and 3 columns.
5. Multimedia
○ Add one image to your webpage.
○ Add an audio or video element.
6. Semantic Elements
○ Use <header>, <nav>, <main>, <section>, and <footer>.
7. Interactive Elements
○ Use <details> and <summary> to display additional information about
yourself.
○ Add a clickable button.
