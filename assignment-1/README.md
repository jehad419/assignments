1.Student Grade Calculator
  
  * Takes a student's name as input.
  * Takes marks for 3 subjects.
  * Calculates:
      o Total marks
      o Average marks
  * Determines the grade using:
      o 80–100 → A+
      o 70–79 → A
      o 60–69 → B
      o 50–59 → C
      o Below 50 → F
  * Displays the result using a formatted string (f-string).


2. Shopping Cart
    * Takes the customer's name as input.
    * Takes the names and prices of 3 products as input.
    * Calculates:
        o Subtotal
        o Discount
        o Final Total
    * Determines the discount using:
        o 5000 or above → 20% discount
        o 3000–4999 → 10% discount
        o 1000–2999 → 5% discount
        o Below 1000 → No discount
    * Displays the shopping summary using a formatted string (f-string).
